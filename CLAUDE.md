# Click2Lead — Consignes de travail

Site vitrine statique (HTML/CSS/JS en un seul fichier par page, styles et scripts inline, sans build). Déploiement automatique GitHub → Netlify depuis la branche `main`. Les démos clients sont servies sous `/demo/<client>/`.

## Approche (efficacité tokens)
- Lire les fichiers concernés avant de les modifier ; ne pas les relire s'ils n'ont pas changé.
- Réflexion approfondie, réponse concise : aller à l'essentiel, pas de remplissage.
- Ne pas relire un gros fichier en entier quand une portion suffit.
- Pas de formules d'ouverture flatteuses ni de conclusions creuses.
- Ne pas deviner les APIs, versions, flags, SHA de commit ou noms de paquets : vérifier dans le code ou la doc avant d'affirmer.

## Style (préférences du projet)
- Répondre en français.
- Les emojis sont autorisés (ton chaleureux assumé).
- Vérifier le rendu en headless (Chromium + serveur local) avant de déployer un changement visuel.
- Règle stricte pour les prospects/clients : n'afficher que des informations réelles (avis, chiffres, coordonnées), jamais inventées.
